# Security policy

AquilaDB handles data about people, so we take each security report seriously.

## Report a vulnerability

**Do not open a public issue for a vulnerability.** Use [private vulnerability reporting](https://github.com/FranciscoSerranoBaptista/AquilaDB/security/advisories/new) on this repository.

Include:

- The part of the system that is affected.
- The steps that show the problem.
- The effect that you expect, for example data exposure or a bypass of the cohort floor.

Do not include real personal or clinical data in the report.

## What to expect

- We confirm that we received the report within 7 days.
- We tell you what we decide to do and when.
- We credit you when we publish the fix, if you want credit.

## Supported versions

Only the latest release gets security fixes. The current release is `v1.1.1`.
